## What it is

🍳 A complete recipe manager for WordPress. Publish a proper recipe in three steps: add it, pick a layout and save it as a reusable **View**, then drop in the `[plugixa_recipe]` shortcode or the Recipe block.

- **Recipes** - unlimited recipes, categories, cuisines and courses; grouped ingredients and instructions, prep and cook times, servings and 11 diet flags
- **Four layouts** - grid, slider, masonry and list, each with a built-in dark mode, styled through saved Views and a visual view editor
- **Nutrition facts** - an FDA-style label with up to 15 nutrients, a serving size and percent daily values
- **Reviews and favourites** - 5-star reviews with photos and admin replies, an optional Cloudflare Turnstile captcha, and a page with each visitor's saved recipes
- **Recipe pages** - a servings adjuster, a clean print view, and automatic, filterable category and cuisine archives
- **SEO** - schema.org Recipe structured data (JSON-LD), recipes in WordPress's own sitemap, Open Graph and Twitter Card meta, clean URLs
- **Recipes in posts** - a whole recipe inside any post or page with "Jump to recipe" and "Print recipe" buttons, or several as a numbered round-up
- **Everywhere you build** - two Gutenberg blocks, an Elementor widget, 8 widget shortcodes, WPML and Polylang support
- **For developers** - a REST API (`plugixa-recipe/v1`), action and filter hooks, and template overrides

The **AI Recipe Generator, custom fields, import and export** (CSV, JSON, and from WP Recipe Maker, Tasty Recipes, Create by Mediavine, WP Delicious, Cooked, Zip Recipes and Recipe Card Blocks), the **SEO analyzer, demo content and WooCommerce integration** are part of Plugixa Recipe Pro. A full tour is on the [documentation](https://www.plugixa.com/documentation/plugixa-recipe?utm_source=github.com&utm_medium=repo_readme&utm_campaign=plugixa-recipe&utm_content=docs) - and on the [WordPress.org plugin page](https://wordpress.org/plugins/plugixa-recipe/).

## Who is it for?

Recipe blogs and food sites that want good-looking recipe cards without building a theme for them. Publishers who want their recipes eligible for Google's recipe rich results. Sites with long category pages, multilingual sites on WPML or Polylang, and anyone building pages in Gutenberg or Elementor.

## Get it

The free plugin itself is hosted on WordPress.org - install it from your dashboard (**Plugins → Add New → search "Plugixa Recipe"**) or fetch it directly:

```
Latest release:  https://downloads.wordpress.org/plugin/plugixa-recipe.latest-stable.zip
Install by ZIP:  Plugins → Add New → Upload Plugin → choose the ZIP → Activate
Requires:        WordPress 6.5+, PHP 8.0+
```
